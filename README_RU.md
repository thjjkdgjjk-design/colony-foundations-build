# Colony Foundations — экспериментальный прототип для Fabric

**Цель сборки:** Minecraft 1.21.5, Fabric Loader, Fabric API, JDK 22. Мод компилируется в Java 21 bytecode для совместимости с требованиями Minecraft.

## Что реализовано
- Блок ратуши колонии с сохранением состояния проекта.
- Контракт строителя: назначает обычного жителя строителем.
- Встроенный простой чертёж коттеджа на ванильных блоках.
- Житель подходит к стройплощадке, а блоки ставятся поэтапно.
- Заказ и прогресс сохраняются в NBT.
- ПКМ по ратуше запускает/показывает заказ; Shift+ПКМ ставит строительство на паузу или возобновляет.

## Чего пока нет
Это не полный порт MineColonies. Пока нет полного набора профессий, экономики, складов, меню, охранников, обучения и полного Structurize. Чертёж коттеджа встроен и фиксирован.

## Установка
1. Скачай release JAR, который не помечен `sources`.
2. Помести JAR в `.minecraft/mods`.
3. Установи Fabric Loader для Minecraft 1.21.5 и совместимую Fabric API версии.
4. Начни с нового тестового мира или копии мира.

## Как проверить в игре
1. Создай мир в Creative.
2. Возьми Town Hall из вкладки функциональных блоков или скрафти его.
3. Поставь ратушу на ровной поверхности.
4. Возьми Builder Contract и нажми ПКМ по обычному жителю.
5. Нажми ПКМ по ратуше, чтобы начать заказ.
6. Дай жителю время дойти до площадки рядом с ратушей. Строительство идёт небольшими шагами.
7. Shift+ПКМ по ратуше ставит заказ на паузу или возобновляет его.

Ратуша строит коттедж рядом с собой. Для первого теста освободи площадку примерно 7×7 блоков к востоку от неё. Прототип пропускает занятые клетки, чтобы не сносить существующие блоки.

## Сборка
Сборка в GitHub Actions использует JDK 22 и Gradle 8.12. Успешная сборка прикладывает JAR к GitHub Release. Сборка в этом репозитории ещё должна пройти CI; не считай мод проверенным, пока workflow не завершится успешно.

## Отладка
Если игра вылетела, приложи `logs/latest.log` и файл из `crash-reports`. Этот прототип экспериментальный; проверяй на копии мира.

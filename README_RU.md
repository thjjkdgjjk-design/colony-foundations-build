# Colony Foundations — экспериментальная колония для Fabric 1.21.5

Цель сборки: Minecraft 1.21.5, Fabric Loader и Fabric API. Сборка выполняется на JDK 22, но байткод выпускается для Java 21, а метаданные допускают Java 21+ — это соответствует требованиям Minecraft 1.21.5.

## Интерфейс строительства
- ПКМ по ратуше открывает каталог построек — вводить команды не нужно.
- Встроена стартовая схема коттеджа.
- Дополнительные постройки загружаются из совместимых datapack, на использование и распространение которых у вас есть необходимые права.
- Перед запуском можно повернуть чертёж на 0°, 90°, 180° или 270°.
- Заказ, выбранная схема, поворот и прогресс сохраняются в NBT ратуши.
- Кнопка «Пауза / продолжить» управляет строительством из интерфейса.
- Обычного жителя назначает строителем контракт из мода.
- При занятой позиции, выходе за границу мира, недопустимой высоте или незагруженном чанке заказ приостанавливается с указанием причины и координат; прогресс и ресурсы не расходуются для заблокированного блока.

## Импорт чертежей
Загрузчик читает собственные JSON-чертежи Colony Foundations и сжатые NBT-файлы формата Structurize v1 с палитрой блоков и упакованным массивом. Публичная сборка временно не скачивает и не включает оригинальные NBT-схемы MineColonies: для закреплённой ревизии не подтверждено явное разрешение на распространение этих файлов. Можно установить совместимый datapack со схемами, использование и распространение которого разрешено его лицензией. Подробности — в THIRD_PARTY_NOTICES.md.

Для безопасности импортируются только блоки и состояния блоков. Данные блок-сущностей, сущности, специальные блоки-подстановки Structurize и команды из оригинальных схем не исполняются. Если в мире отсутствует блок из другого мода, он заменяется воздухом. Пустые клетки оригинального чертежа не удаляют существующие блоки игрока.

## Чего пока нет
Это не полный порт MineColonies или Structurize. Пока отсутствуют все профессии и их ИИ, склады и экономика, этапы повышения уровня здания со снабжением, полноценный предпросмотр-призрак как в Structurize, редактор чертежей, все стили и типы построек. Интерфейс и размещение схем — следующий фундамент для дальнейшей работы, но игровое тестирование всё ещё нужно.

## Установка
1. Скачай последний JAR из GitHub Releases.
2. Удали предыдущую версию Colony Foundations из .minecraft/mods, чтобы не было дубликатов.
3. Установи Fabric Loader и Fabric API для Minecraft 1.21.5.
4. Проверь в новом творческом мире или копии мира: поставь ратушу, назначь жителя контрактом и выбери встроенный коттедж. Для других построек сначала установи совместимый datapack со схемами, на которые распространяется лицензия, разрешающая такое использование.

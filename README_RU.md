# Colony Foundations — прототип для Fabric 1.21.5

**Цель сборки:** Minecraft 1.21.5, Fabric Loader, Fabric API, JDK 22. Код компилируется в байткод Java 21 для совместимости с Minecraft.

## Что есть
- Ратуша колонии с сохранением состояния строительного заказа.
- Контракт для назначения обычного жителя строителем.
- Отдельная система чертежей на основе JSON-ресурсов датапаков.
- Чертёж коттеджа поставляется как JSON; встроенная запасная схема используется, если файл отсутствует или повреждён.
- Строитель постепенно размещает блоки; прогресс проекта сохраняется в NBT.
- Загрузка чертежей повторно выполняется при /reload.

## Формат чертежа

Файл нужно положить по пути data/<namespace>/colony_blueprints/<имя>.json. Например, data/colony_foundations/colony_blueprints/cottage.json имеет идентификатор colony_foundations:cottage.

Минимальный пример:

    {
      "format": 1,
      "blocks": [
        { "pos": [0, 0, 0], "block": "minecraft:oak_planks" },
        {
          "pos": [1, 0, 0],
          "block": "minecraft:oak_stairs",
          "properties": { "facing": "east", "half": "bottom", "shape": "straight", "waterlogged": "false" }
        }
      ]
    }

- pos — координаты блока относительно точки привязки.
- block — идентификатор блока, например minecraft:oak_planks.
- properties — необязательные свойства состояния блока.
- Ограничения безопасности: до 8192 блоков в схеме, координаты от -128 до +128.
- Некорректные схемы пропускаются; встроенный коттедж остаётся запасным вариантом.

Это собственная небольшая система для Colony Foundations. Она пока не читает родные файлы Structurize, не является официальным Structurize и не превращает прототип в полноценный порт MineColonies.

## Установка и проверка
1. Скачай JAR из последнего успешного GitHub Release и помести его в .minecraft/mods.
2. Установи Fabric Loader для Minecraft 1.21.5 и совместимую Fabric API.
3. Проверь мод в новом творческом мире или в копии мира.
4. Для первого теста освободи площадку рядом с ратушей и назначь строителя контрактом.
5. Если игра вылетает, приложи logs/latest.log и файл из crash-reports.

## Сборка
GitHub Actions собирает мод с JDK 22 и Gradle 8.12. Успешная сборка прикладывает JAR к тестовому релизу. Компиляция сама по себе не подтверждает, что все игровые механики проверены в реальном мире.
